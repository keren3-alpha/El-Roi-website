# El-Roi | Contemporary Interiors Website

A modern, responsive interior design portfolio website for El-Roi, a contemporary interior design studio.

## Live Demo

[https://Cherubin.pythonanywhere.com](https://Cherubin.pythonanywhere.com)

## Features

- Fully responsive design (desktop, tablet, mobile)
- Smooth GSAP animations
- Interactive portfolio gallery with modal popups
- Service cards and client testimonials
- Contact form with email integration
- iPhone mockup preview

## Technologies

- HTML5, CSS3, JavaScript
- GSAP for animations
- Font Awesome icons
- Google Fonts (Inter, Cormorant Garamond)
